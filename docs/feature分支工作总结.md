## 主要功能模块

### 1. 资源管理系统（已完成 ✅）

**核心功能**:
- 资源 CRUD（创建、查询、更新、删除）
- 多版本管理（每次更新创建新版本）
- 敏感信息加密（密码、Token、密钥）
- 父子资源关系（数据库 → Schema → 用户）
- 作用域隔离（平台/环境）
- 权限控制（view、manage、reveal）

**资源类型** (9 种):
- GaussDB 数据库、Schema、用户
- Redis 缓存
- Kafka 消息队列
- MQS 队列
- 配置中心
- IAM 身份认证
- 通用端点

**技术实现**:
- Store 层: `swr_builder/store/resources.py` (~580 行)
- 资源类型系统: `swr_builder/delivery/resources.py` (~351 行)
- API 层: `swr_builder/api/resources.py` (~180 行)
- 前端页面: `web/src/views/resources/` (3 个组件)

**最近优化**:
- ✅ 完善父链展开逻辑（提交 939f4d6）
- ✅ 自动查询和解密父子资源
- ✅ 正确记录父链到发布快照

### 2. 环境预置系统（已完成 ✅）

**核心功能**:

## 架构设计

### 分层架构
```
前端层 (Vue)
  ↓
API 层 (FastAPI)
  ↓
Service 层 (业务逻辑)
  ↓
Store 层 (数据访问)
  ↓
数据库层 (PostgreSQL)
```

### 数据流
```
用户操作
  ↓
表单验证
  ↓
API 请求
  ↓
业务逻辑处理
  ↓
数据库操作
  ↓
返回结果
  ↓
UI 更新
```

### 配置解析流
```
服务发布
  ↓
加载服务配置
  ↓
查询资源绑定
  ↓
展开父链
  ↓
解密敏感属性
  ↓
计算导出
  ↓
合并配置层
  ↓
生成 Kubernetes YAML
  ↓
应用到集群
```

## 已知问题和限制

### 当前限制
1. **资源类型扩展**: 需要同时修改后端和前端代码
2. **父子资源层级**: 当前支持 3 层（数据库 → Schema → 用户）
3. **批量操作**: 暂不支持批量导入/导出资源
4. **资源使用追踪**: 未实现反向查询（哪些服务使用了该资源）
5. **预置版本管理**: 预置本身没有版本控制

### 待优化项
1. **性能优化**: 大量资源时的列表查询性能
2. **批量导入**: 支持 CSV/YAML 格式批量导入
3. **健康检查**: 定期检查资源可用性
4. **使用统计**: 统计资源使用情况和趋势
