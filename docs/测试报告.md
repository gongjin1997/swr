## AK/SK 专项验证

新增 tests/test_hcs_aksk.py 和官方 SDK 固定签名向量 tests/signing_vectors.json：

- 与华为独立官方签名示例 SDK 2.0.7 的固定输出一致。
- 模拟 IAM 服务独立重算规范请求和 HMAC，对实际 HTTP 字节/头做校验，不用同一个被测函数自证。
- 零字节请求体、带端口 Host、UTF-8 JSON 长度、项目/账号作用域、临时 Security Token。
- 12 个并发认证只发出一次，缓存命中、提前刷新、服务 GET 的 401 有界重试。
- 错误 AK/SK、非法模板、SK 禁止进入 body、缺 scope、返回 scope 不匹配、过期、缺 Token、坏 JSON、上游错误、重定向拒绝。
- 页面/API 候选测试不落库、AK/SK 加密不回显、环境变量锁定。

测试不证明现场 IAM 接受默认空体或当前 Access 签名版本，需真实网关验收。
