## 💎 最佳实践

### 1. 两阶段渲染

```
参数装配（五级覆盖）
  ↓
渲染 values.yaml
  ↓
渲染 K8s 对象
```

**优势**:
- 参数来源清晰
- 模板易于维护
- 高度可复用

### 2. 配置优先级

```
7. Platform Secret  (最高)
6. Platform Common
5. Environment Secret
4. Environment Common
3. Service Secret
2. Service Common
1. Default          (最低)
```

**优势**:
- 语义明确
- 防止误覆盖
- 支持锁定

### 3. 完整的就绪判断

```python
# XAC 标准的就绪检查
observedGeneration == generation  # 确保是最新版本
updatedReplicas == replicas       # 所有副本已更新
availableReplicas == replicas     # 所有副本可用
Progressing != False              # 没有进度失败
```
